# Alfred Core

Phase 1 executive command centre for Alfred, Patrick King's AI Operating Partner.

## Run

The app has no build step or package dependencies:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included

- Persistent company registry for Digitize Consultants, Product Studio, AI Venture Studio and Media Studio
- Executive command dashboard derived from real local records
- CEO morning briefing generated from open actions, risks, opportunities and decisions
- Local institutional memory with search and record creation
- Agent management framework with explicit inactive status until runtimes and tools exist
- Integration architecture with honest connection states
- Responsive J.A.R.V.I.S-inspired command centre UI

Data is stored in the browser under the `alfred-core-v1` local storage key. External systems are not connected and the UI states this explicitly.
