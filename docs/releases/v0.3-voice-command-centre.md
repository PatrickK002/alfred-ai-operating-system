# v0.3 Voice Command Centre

Read-only voice interface for Alfred.

- Voice Command Centre in the executive dashboard.
- Deepgram speech-to-text adapter.
- ElevenLabs text-to-speech adapter.
- Typed transcript fallback.
- Voice conversation history and audit logging.
- Advisory routing to Alfred, Sarah, Olivia and Westbridge.
- No autonomous execution and no external write actions.
